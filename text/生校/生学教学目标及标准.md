# 生学教学目标及标准

目标：**使学员掌握生道与生制，形成稳定的判断与行动能力，为生门输送合格的候选门人。**

生学是生校的核心学科，包括生道和生制。生道提供共同的目标、原则与价值判断依据；生制是生道在现实的核心执行机制。

本文依据[《生制》](../生制.md)与[《生制宪章》](../生制宪章.md)，将培养要求落实为教学目标与达标表现。教学标准由生门指定，成果由生门评价；生校自主决定符合要求的教学方式。

## 总体目标及标准

目标：**使学员能够依据生道判断，运用生制做事，长期稳定创造价值。**

学员应能贯通目标、判断、行动与结果：讲清为何做，判断该做什么，在职责范围内做成，依据结果纠正偏差。

达标须同时体现于理解、判断和行动。能背诵条文而不能用于实际选择，或能说明原则而行动持续背离原则，均不算达标。

## 生道教学目标及标准

目标：**建立生道坐标系，使学员以生者正义、大者胜利判断是非与取舍，并落实于行动。**

| 教学内容 | 教学目标 | 达标表现 |
| --- | --- | --- |
| 根本目标 | 理解生道的生生不息及生制为生道服务的关系 | 能说明生道、生制与具体组织的目标关系，不把某个组织的存续等同于生道的存续 |
| 生者正义 | 以是否利于生判断是非 | 面对具体事情，能依据事实判断其是否有利于长久繁荣，识别局部利益对更大范围的生的损害 |
| 大者胜利 | 在两难中作出取舍 | 能比较方案的受益范围、持续时间与发展质量，选择更利于长久繁荣的方案，不以权力、人数或财富代替判断 |
| 代价与收益 | 为实现目标承担必要代价 | 能说明所选方案的代价与最终收益，判断收益是否大于代价，并在实际行动中承担该付的代价 |
| 日常践行 | 使判断成为稳定行为 | 在日常及压力、利益、失败、冲突和诱惑中，仍能依据同一标准行动、承担责任、纠正偏差 |

## 生制教学目标及标准

目标：**使学员掌握生道落实为组织秩序的方式，在明确的身份、权责与规则内协作做事。**

| 教学内容 | 教学目标 | 达标表现 |
| --- | --- | --- |
| 组织与身份 | 明确各类组织的目的及个人所处身份 | 能分清生门、生组、生财、生校，以及行生者、生生、组员、候选门人、股东、职务、学员；能说明自身当前身份及相应责任，不把入学或候选等同于加入生门 |
| 组织建构 | 从目标形成必要分工 | 能围绕具体目标说明核心运转流程，据此提出必要分工与协作安排，不以机会代替组织目标 |
| 决策与执行 | 按专业分工及级别作出、执行和反馈决定 | 能识别谁有决策权、谁负责执行；上级已决时忠实执行，异议另行上报；后果可能影响其他级别时先上报，不越权处置 |
| 资产与分配 | 正确识别权利主体及分配依据 | 能分清公共资产、组织资产、个人资产；能在案例中按产权比例计算产出分配，依据功劳分析产权变化，并分清常规价值与结构价值，不以身份或荣誉代替财产权利 |
| 任务与生产 | 将目标分解为可执行、可检验的任务 | 能在理解业务的基础上分割任务，明确责任与成果要求，完成所承担的任务并说明实际贡献 |
| 效力与纠错 | 依宪章处理规则和行动中的偏差 | 能识别组织规则与宪章的冲突，按既有渠道反馈、申诉或举报；出现问题时先止损、保核心，再纠错，不以新制或口号代替处理问题 |
| 文化与传习 | 在日常协作中保持共同语言和行为标准 | 能准确使用共同概念，以实际做事示范，纠正混称与行为偏差；能带他人掌握并独立运用已有做法，不把礼仪、仪式或头衔当作实际成果 |

## 教学实施要求

目标：**使所学进入实际判断与行动，形成可持续验证的能力。**

- 先建立生道坐标系与判断—行动闭环，再展开生制细目及其他学科。
- 每项内容均结合讲解、案例判断、行动训练与结果复盘；案例和练习须能回溯到现行正文。
- 教师先示范，再带着做，逐步让学员独立完成；发现词义、判断、行为或身份偏差时，当场纠正。
- 教学必须结合真实实践。实践机会通常由生组提供，明确学员承担的任务、职责范围与成果要求。

## 考核及达标判断

目标：**以理论掌握和持续的真实表现，验证学员是否达到教学要求。**

### 考核依据

目标：**让每项评价都有可检查的事实依据。**

- **生道测验**：检验对目标、原则及其制度落实的理解，以概念说明和案例判断考察学员能否独立说明依据、比较方案、作出选择。
- **股东横评**：结合真实实践评价学员的实际贡献、协作与责任承担。
- **持续观察**：记录日常以及压力、利益、失败、冲突和诱惑中的真实表现，观察判断与行动能否保持一致。

评价记录应写明对应要求、具体事实、实际结果、存在偏差及纠正后的表现。不能只记分数、评语或态度表态。

### 达标认定

目标：**确认学员能够持续运用所学，而非一次答对或偶然做成。**

达标应有以下表现及相应证据：

- **理解准确**：能用自己的话说明核心目标、概念与规则，不混用关键身份、资产及分配口径。
- **判断独立**：面对未练过的具体问题，能依据事实运用生者正义、大者胜利作出判断，并说明代价与收益。
- **行动有效**：在真实任务中忠实执行、有效协作、承担责任，产出可检验的结果。
- **表现稳定**：在不同任务及利益、压力等情境中持续践行，发现偏差后能纠正，并在后续行动中验证改进。

缺少实践证据或尚不能稳定做到的，继续训练与观察。具体测验、观察安排和认定要求，落实生门指定的标准。

### 结果运用

目标：**将评价用于改进培养与候选人推荐。**

依据未达标内容安排后续学习和实践；依据学员表现及生门评价改进教材、教学方法与考核。

生学达标是候选人推荐的培养依据，不能代替生门对价值观、人格、能力、责任、信用等方面的要求与考察。向生门推荐时交接培养与评价记录；学员、候选门人与生生身份不自动转换。

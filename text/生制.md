# 生制

生制是一套秩序建构方式。

生制为生道服务，是生道在现实的核心执行机制。

生制由以下核心要素构成：

**生道**：最高精神，提供共同的目标、原则与价值判断依据，指引组织建设和体制运行。

**生门**：生制创生组织，是维护和发展生制，践行生道的核心组织。

**生组**：在生制宪制框架下运行的组织。任何认同生道理念的人都可以创办生组。生制宪制确立各生组共同遵循的核心规则。

**生财**：盈利性生组。核心目的为盈利，且已成为生组，即为生财。

**生校**：教育性生组，为生门服务，向生门输送候选门人。生校资格需要生门授权。

## 组织类型

生门是创生机关：维护和发展生制，制定宪制，授权、背书、裁决。

生组是在生制宪制框架下运行的组织。生财、生校是生组。不是生财、也不是生校的，仍称生组，不另立名称。

```
生制下的组织类型
├── 生门：生制核心
└── 生组：在生制宪制框架下运行的组织
    ├── 生财：盈利性生组
    └── 生校：教育性生组
```

### 生门

生门负责生道的理念与组织建构。是生制创生组织，维护和发展生制，践行生道。

核心目的不是盈利。本身不对外经营。

核心职能：精神建设、组织建设、标准制定、授权背书、资源分配、争议裁决。

成员称为生生，也称门人、生门成员。进入、退出、转换均需评审。

生门作为组织，有公账与产权等资源。组织资产的分配，预算从上到下，由各级层层表决分配；具体支出由下到上层层申请，到适用的分配级别后划拨。生门另管理公共资产，用于共同事务，不向生生个人分配。公共资产与生门自身的组织资产分称。

生门作为核心组织，无法转为生组、生财或生校或任何其他类型的组织。生门长期存在，不适用清退、撤销等退出机制。

#### 其他说明

- 生门具有唯一性。
- 公共基础由生门内部相关职能运营。

### 生组

生组是在生制宪制框架下运行的组织。

生组成立人员要求：1 人。

成立生组就意味着，认同生道理念，遵守生制宪制，接受生制约束与监督。

核心目的由该生组自定，不得违反生制宪制。

内部运营细则自行决定，默认不公开。

必须自行公示：名称、组织目标、负责人。其余可以不公开。生门不维护生组名单。抽查或举报时，对的是已公示的三项，以及是否违宪。

须在宪制框架下运行，不可违宪。监督任何人都可以做，通常以组员为主要监督力量。违宪可向生门举报。

成员称为组员。股东是产权身份，不是成员身份。二者可重叠，不自动转换。

每个生组是一个实体，有公账与产权等资源。组织资产的分配，预算从上到下，由各级层层表决分配；具体支出由下到上层层申请，到适用的分配级别后划拨。

生组可以下设或控股另一个生组。每个生组都是独立实体，各自公示三项、各自有公账。内设部门、小组不是生组。

背书须经生门审核。撤销背书后，只要仍符合生组要求，仍是生组。

符合目标类型的要求，即可转换类型。

对生组启动清退，清退完成后，不再享受生组权利，不再承担生组义务；其生财或生校身份一并解除。

必须分清：

- 生组与生门
- 生组与内设部门
- 组员与股东
- 公示三项与内部运营

### 生财

生财是盈利性生组。核心目的为盈利，且已成为生组，即为生财。

不是所有赚钱的组织都是生财。

任何人可创办。现存实体成为生组，且核心目的为盈利，即转为生财。

生组通例全部适用。产权、用工、对外合同，以及用什么方式盈利，由该生财自定。

生财办教育，是生财内部事务，不因此成为生校。生校须经生门授权。

决策仍适用生者正义与大者胜利，生财不例外。

符合要求可转换类型；转为生校须另经授权。

必须分清：

- 生财与尚未成为生组的经营实体
- 核心目的盈利与是否收款
- 生财内部教育与生校

### 生校

生校是教育性生组，为生门服务：发掘、培养、验证，向生门输送候选门人。可复制，须通过生门评审并获得授权。任何人都可以申请授权。未经授权，不是生校。

核心目的不是盈利。核心目的统一：让学员通过生门评审。只面向成人。可以收款；在可能亏损时仍须运营。盈余沉淀在生校公账，不按盈利组织分配。

教学标准由生门指定，成果由生门评价。教学方式由生校自主决定，必须符合生门的要求和标准。

生组通例全部适用。成员仍称组员。学员属于生校，不属于生门；学员不因其在校而成为组员、股东、候选门人或生生。进入生校本身可以有独立价值，不改变生校为生门服务的目的。

撤销授权后，不再是生校；已发放的仍然有效，记录转移至其他生校。只要仍符合生组要求，仍是生组。清退仍从生组。

必须分清：

- 生校与生财
- 学员与组员、股东
- 进入生校与进入生门
- 收款与核心目的盈利
- 撤销授权与清退
- 生财内部教育与生校

## 通用体系

通用体系覆盖所有生组共同遵循的规则。

### 宪制

要明确组织运行的最高规则。

#### 目标

要明确最高规则所服务的目的。

##### 生制目标

给出各组织必须对准的根本目标。

生制的根本目标，是**生生不息**。

天道的生生不息滋养组织，组织的生生不息滋养个体，个体的生生不息反哺组织，组织的生生不息反哺天道。

生，是一切秩序的存在基础，是一切的动力源头，也是人的一切思想、言行的唯一合法性来源。

##### 组织目标

要明确组织的根本目标，为什么存在。

#### 组织建构

要明确组织如何从目标形成分工与结构。

组织的目标决定了分工，分工决定了建构。

要先明确组织的核心运转流程，涉及哪些分工。

#### 决策

要明确决策的流程与标准。

##### 决策标准

要明确判断对错与取舍的标准。

###### 生者正义

要明确是非判断的标准。

是非判断以是否有利于组织的生生不息（长久与繁荣）为准。

组织的生须嵌于更大范围的生，不得以小生换大生，以长生换短生。

组织与环境的关系是和谐共生的。组织对环境的影响应该是正向的、积极的，让人愿意亲近的。对外友好开放，对内持续精进。

###### 大者胜利

两难选择选大的。

在符合“生者正义”的前提下，哪种选择能让组织更长久繁荣，就选哪种。

对“大”的判断，应综合考虑最终的长久繁荣度，包括受益范围、持续时间与发展质量，不以权力大小、人数规模或财富数量作为衡量尺度。

##### 决策代理

要确保专人专断。

专业的事情，交给专业的人决策。专人由同级分工选举产生。

每个分工的最高决策者，由同级别、同分工的成员共同选举产生。不可跨分工、跨级别选举。

##### 决策执行

要确保决策被及时准确的执行。

上级决定的，下级必须接受并忠实执行。

一个级别的决定只能影响自己的级别。

如果决策后果可能影响其他级别，应先上报，等待上级回复。

组织资产按此调配：预算从上到下，由各级层层表决分配；具体支出由下到上层层申请，到适用的分配级别后划拨。

如对上级决定有异议，可以另行上报反馈。

##### 异议申诉

要确保争议有跨级反馈的通道。

#### 分配

要明确成果记到谁、产权如何变。

##### 产出分配

要明确已形成的产出按什么分给权利人。

占比越大，分配越多。

按产权（股权）比例，对权利人进行周期性分配。分配内容为组织在上一个分配周期内的产出。

##### 产权分配

要明确产权因功劳如何变化。

功劳越大，分配越多。

功劳，就是对组织发展（使组织更加繁荣长久）的贡献。一个股东产权的变化，取决且仅取决于其是否让组织更强了。

常规价值：能用钱量化、可在市场找到对应参考的贡献，按等价折为股权。

结构价值：无法直接在市场买到的贡献。功劳大小，众人判断，长期验证，多留少补；滞后性高的贡献，随组织发展多次表决补发。

#### 生产

要确保任务被准确分割，及时执行。

准确的任务分割，有赖于准确的判断力；准确的判断力有赖于判断者对其业务的深入理解。

准确的任务分割，可以提高生产效率。

#### 效力

宪制的适用范围。

##### 适用范围

本宪制是各生组共同遵循的根本规则，适用于各生组、其治理机构及组员的一切组织活动。

##### 最高效力

本宪制具有最高效力。

任何组织、成员、制度，不因为任何原因而享有超越宪制的特权。

生制细则与本宪制具有同等效力。

##### 内部治理

要明确各组织在宪制内可自定更细制度。

各组织在宪制框架内，依据自身职能和实际情况探索最佳实践，制定具体制度，切实坚定执行，并承担相应责任。

生组内制度不得违反生制宪制。生门内部制度由生门自定，与生组内制度分称。

### 文化

使生道进入日常。

在日常生活中，使人潜移默化地受益。

#### 认知

概念对齐词义，语言对齐日常说法。词义以宪制为准，文化负责进入日常。

必须共同理解：

- 生生不息

  - 行生者的核心礼仪用语，可用于问好、告别、致谢、安慰、哀悼
- 生道、灭道、行生道、取灭道
- 行生者、取灭者

- 组织类型
  - 生门：生制创生机关
  - 生组：在生制宪制框架下运行的组织

  - 生校：教育性生组，为生门服务，向生门输送候选门人；须生门授权
- 组织与成员的身份对应
  - 生生：生门成员
  - 组员：生组成员
  - 候选门人：生校向生门输送的候选人，不是生生
  - 股东：持有某生组股权的人
  - 职务：在某组织中的任职

- 权力
- 功劳
- 产出分配、产权分配
- 常规价值、结构价值
- 公共资产、组织资产、个人资产
- 背书、授权、清退

必须分清，不得混用：

- 撤销背书、撤销授权、清退
- 生道与某个具体组织的存续
- 行生者与组织成员
- 身份与财产
- 生生、组员、候选门人、股东、职务、学员
- 组员与股东
- 组员与学员
- 产出分配与产权分配
- 专业判断与私人利益处置

- 生门不盈利与生财创造价值

词义由宪制给定，不因习惯、职位或局部利益改义。

##### 语言

同一件事用同一套说法。决策、评价、分配、协作时，直接使用共同概念，不必每次重新解释。

- 决策：生者正义、大者胜利、代价与收益
- 分配：占比、功劳、常规价值、结构价值
- 身份：生生、组员、候选门人、股东、职务、学员分称
- 同道：行生者、取灭者分称，不与组织身份混称
- 礼仪：生生不息，可用于问好、告别、致谢、安慰、哀悼
- 组织：生门、生组、生财、生校分称
- 进出：背书、授权、清退分称
- 资产：公共、组织、个人分称

语言必须指向可检验的事实与结果，不能用口号代替判断。

出现词义漂移、口号化、故意混称时，先纠正说法，再处理其事。

#### 行动

规范约束日常言行。判断方式是把宪制中的生者正义与大者胜利做成习惯，不另立标准。

先判断，后行动。判断对齐标准，行动对齐结果。

##### 行为规范

必须做到：

- 做事：把事情做成，结果可检验
- 发言：够专业，才发言
- 执行：上层已决，当时忠实执行；异议另行上报
- 边界：本级决定只影响本级；可能影响他级，先上报
- 对人：对外友好开放，对内持续精进
- 财产：分配先明确权利主体；身份与财产分开处理

不得：

- 用专业判断处置他人私人利益
- 跨分工、跨级别决策
- 以机会代替组织目标
- 混用身份、资产与分配口径
- 用口号、仪式或新制代替做事

言行必须指向可检验的共同结果。做不到的，先纠正行为，再处理其事。

##### 判断方式

遇到选择，按同一顺序判断，不另立标准：

1. 是否利于生（生者正义）；组织中落实为是否有利于组织长久繁荣，且不得伤害更大的生
2. 哪个方案惠及更广、延续更久、发展质量更高（大者胜利）
3. 最终收益是否大于代价；该付的代价要付

“大”看受益范围、持续时间与发展质量，不以权力、人数或财富衡量。

日常用于：

- 决策：听谁的、做什么、付什么代价
- 评价：功劳、常规价值、结构价值
- 生产：如何分割任务
- 冲突：先止损、保核心，再纠错
- 存续：背离生道的，整顿、撤销背书、撤销授权或清退

必须分清：

- 生者正义与当下舒服、局部利益
- 大者胜利与人多、权大、钱多
- 专业判断与私人利益处置
- 把事情做成与说得好听
- 组织目标与机会

出现用口号、情绪或局部利益代替判断时，先回到生者正义与大者胜利，再处理其事。

#### 归属

行生者认同生道理念，是松散的同道中人，不是组织成员。

成员认同自己属于生制。生生、组员、候选门人、股东、职务、学员可以重叠，不混为同一种身份，也不与行生者混称。

认同落到身份与责任，不落到气氛、口号或私人关系。

##### 身份认同

必须共同确认：

- 自己属于生制，不只是在某个组织做事
- 认同生道理念，不等于加入任何组织
- 当前在用哪一种身份说话、做事、取酬
- 身份与组织对应：
  - 生生：生门成员
  - 组员：其所在的生组
  - 候选门人：由生校输送给生门，尚未成为生生
  - 学员：生校，不属于生门
  - 股东：其所持股的生组或生财
  - 职务：其所任职的组织

必须分清：

- 属于生制 与 属于某个具体组织
- 行生者 与 生生、组员、候选门人、股东、职务、学员
- 生生、组员、候选门人、股东、职务、学员
- 组员与股东
- 组员与学员
- 身份与财产
- 进入生校 与 进入生门
- 候选门人 与 生生
- 创办生组 与 获得生门背书
- 生道 与 某个具体组织的存续

各身份可以重叠，不自动转换：

- 行生者不因其认同而成为生生、组员、候选门人、股东、职务或学员
- 学员不因其在校而成为组员、候选门人、生生或股东
- 候选门人不因其被输送而成为生生
- 生生创办的生组，进入协作网络须经背书
- 股东身份取决于该组织是否接受其贡献
- 生生身份取决于申请、学习与考核
- 退出或解除某一身份，不自动剥夺其他身份，也不自动剥夺已有财产

日常用于：

- 进入：按身份办理，不按关系办理
- 在内：以当前身份承担责任，不拿别的身份越权
- 分配：先明确权利主体，再论产出与产权
- 退出：解除的是该身份，不是把人从生道或财产里一笔勾销

出现把某个组织当成生道、把财产当成身份、或把一种身份当成另一种时，先分清身份，再处理其事。

#### 礼俗

传统是时间筛过的做法。礼仪用语是同道相认的日常标记。仪式把重要节点做成共同记忆。荣誉与禁忌成对：表彰行生道，否定行灭道。

俗是筛过仍在用的做法，礼是公开的标记。先有反复做成的事，才有传统；先有可检验的功过，才有荣誉与禁忌；仪式只标记已经发生的节点。行生者可用核心礼仪用语相认、致意，不因此强制齐备仪式全集。传统随共同行动筛出，不预先设计全集。闭环未稳时，不强制齐备仪式、荣誉与禁忌。

##### 传统

必须确认：

- 传统是反复做成、经时间筛过仍在用的做法，不是事先写好的习俗全集
- 筛的标准仍是生者正义与大者胜利，不另立标准
- 失效、空转、妨碍做事的，淘汰

必须分清：

- 筛过仍在用 与 堆积、怀旧、原样照搬
- 传统 与 一开始设计出来的仪式清单

日常用于：

- 带人、记功劳、过关、协作：沿用已验证的做法
- 新做法先做成、再观察，不未稳先立俗

出现把未验证的做法叫做传统、或用传统挡住纠错时，先回到共同行动的结果，再处理其事。

##### 礼仪

行生者核心礼仪用语：**生生不息**。

可用于问好、告别、致谢、安慰、哀悼等场景。

这句话指向天道与彼此的生生不息，是同道的相认致意与美好祝愿。

要求：

- 可使用场景：传达善意
- 可使用身份：除取灭者以外的任何人
- 此语仅代表愿行生道的立场态度，仅限礼数，无绑定的责任和义务，也不代表拥有组织身份
- 此语为生道的最高核心礼仪用语，不可更改，其他礼法不可与之相悖

##### 仪式

把已经发生的重要节点做成共同记忆。仪式本身不创造价值。

节点包括：

- 加入
- 晋升
- 退出
- 表彰
- 纪念

必须做到：

- 只标记已发生、可检验的节点
- 当时忠实于该身份的进入、升降或解除，不借仪式改财产

不得：

- 用仪式代替做事
- 未稳先齐备
- 叠加新仪式掩盖空转

必须分清：

- 仪式 与 把事情做成
- 共同记忆 与 场面、口号、气氛

出现仪式空转或用新仪式代替纠错时，停用该仪式，先处理其事。

##### 荣誉

公开承认谁行生道、谁让组织更强。

必须确认：

- 荣誉指向可检验的贡献与结果
- 股权是财产，荣誉是名声与示范；二者分开处理
- 与禁忌成对，有表彰必有否定

必须分清：

- 荣誉 与 产权分配
- 荣誉 与 权力、人多、钱多
- 示范 与 气氛、人情、派系

日常用于：

- 表彰让组织更繁荣长久的行为
- 给后来者可仿的样子，不给分配口径

出现把荣誉当股权、或用人情派系发荣誉时，先回到功劳与结果，再处理其事。

##### 禁忌

公开否定行灭道。

必须确认：

- 禁忌指向背离生道、损害组织长久繁荣的行为
- 行为规范管日常底线，禁忌管构成性对立
- 触犯禁忌的，按宪制整顿、撤销背书或解散；禁忌不是另一套处罚

必须分清：

- 禁忌 与 日常不得
- 行灭道 与 代价、失败、异议
- 公开否定 与 整人、派系清算

日常用于：

- 标明不可行的方向：行灭道
- 与荣誉同时出现，避免只剩表彰

出现用禁忌整人、或把失败和异议当成灭道时，先回到生者正义与大者胜利，再处理其事。

#### 传习

传习把认知、行动、归属、礼俗送进人。示范给人看，纠正把人拉回，过继交给下一批。不另立标准。

生校承担学员阶段的教化。生门成员之间的传习，随共同行动发生。不靠文件宣布，不待仪式齐备。

##### 示范

用可检验的做事给人看。荣誉标记谁可仿，示范是带着做。

必须做到：

- 判断、语言、行动对齐宪制，当场做出来
- 以当前身份示范当前责任，不拿别的身份演示
- 结果可检验；做不到的，不拿说法代替

必须分清：

- 示范 与 表演、场面、口号
- 示范 与 荣誉表彰
- 带着做 与 宣布应该怎么做

日常用于：

- 带人、协作、过关：先做给看
- 生校：教判断与行动，不教背条文

出现只会讲不会做、或把场面当成示范时，先回到共同行动的结果，再处理其事。

##### 纠正

把已经偏离的说法、判断、行为、身份拉回同一套标准。不另立标准。

必须做到：

- 词义漂了，先纠正说法
- 判断偏了，先回到生者正义与大者胜利
- 行为偏了，先纠正行为
- 身份混了，先分清身份

必须分清：

- 纠正 与 整人、派系清算
- 纠正 与 禁忌、处罚
- 纠正 与 申诉、问责：纠正改习惯，申诉改决定
- 当场拉回 与 另立新课、新制、新仪式

不得：

- 用文件、课程或新制代替当面纠正
- 把失败、异议当成必须纠正的灭道

出现用纠正整人、或用叠加新课代替拉回时，先停新增，回到已有标准，再处理其事。

##### 过继

把活的判断、行动与传统交给下一批人。下一批人要能自己做成，才算过出去。

必须确认：

- 过继的是做法，不是头衔、股权或仪式清单
- 学员阶段由生校教化；进入生门后，在共同行动里接住
- 身份仍按归属办理，财产仍按已分配的办理，不随过继转移

必须分清：

- 过继 与 权力交接
- 过继 与 产权转移
- 过继 与 代际制度传承
- 过继 与 收徒、私人恩义

日常用于：

- 带下一批人进入同一套判断与行动
- 退出或传承时，把仍在用的做法过出去

出现把过继当成传位、传产或收私人弟子时，先分清传的是做法还是权产，再处理其事。

#### 空心与重建

文化会空转：口号还在，判断与行为已经离开生道。

出现仪式化、口号化、认同瓦解时，停用空壳，回到共同行动中重建。不能用叠加新仪式代替。

### 公共基础

建立整个体制共同使用的基础设施：

- 法律与合规
- 财务与审计
- 信息系统
- 数据系统
- 知识库
- 档案体系
- 品牌体系
- 公共关系
- 风险控制
- 安全体系

公共资产由生门管理，用于共同事务，不向生生个人分配。

经生门背书的组织，使用公共品牌与公共设施，并承担相应纪律。

### 演化

任何制度都不能假定自己永远正确，因此必须建立：

- 反馈机制
- 纠错机制
- 制度修订机制
- 创新机制
- 组织实验机制
- 组织复制机制
- 地域扩张机制
- 代际传承机制

最终使整个体制具备持续适应环境的能力。

核心循环尚未稳定时，优先纠错与巩固，不优先扩张。

## 生门

### 生门定位

生门是生道的创始组织、正统核心、核心成员共同体。

进入生门的人，必须经过长期筛选和验证，达到生门对价值观、人格、能力、责任、信用等方面的要求。

生门的主要功能是：

**聚人、聚资、聚智、聚势，制定标准，背书认证，持有关键资产，裁决争议，使各生组按生道持续创造价值。**

生门本身不盈利。创造利润的主体是生财。

### 生门成员体系

生门成员称为**生生**。

生校向生门输送候选门人。候选门人须经考察，加入后才成为生生。

建立完整的成员生命周期：

**候选 → 考察 → 加入 → 发展 → 承担责任 → 晋升 → 退出或传承**

主要包括：

- 准入标准
- 候选机制
- 成员认证
- 成员权利
- 成员义务
- 成员等级
- 晋升机制
- 降级机制
- 退出机制
- 除名机制
- 退休机制

退出或除名影响的是生生身份，不影响其已取得的个人股权与财产。

### 生门治理体系

建立：

- 决策机制
- 执行机制
- 授权机制
- 监督机制
- 选举机制
- 问责机制
- 罢免机制
- 权力交接机制
- 争议解决机制
- 申诉机制

创始阶段结束后，生门负责人由生生按组织法选举产生。

根本目标是：

**既保证行动效率，又避免权力被个人、派系或局部利益长期占有。**

### 生门资源体系

组织和整合各种资源：

- 资金
- 生生
- 生组与生财
- 股权
- 土地
- 技术
- 知识
- 信息
- 社会关系
- 商业机会
- 品牌
- 数据
- 其他生产资料

形成：

**资源进入 → 登记 → 明确权利主体 → 估值 → 配置 → 使用 → 产生价值 → 回流 → 再配置**

的长期循环。

凡进入分配的资源，必须先明确属于生门公共资产、某生组资产，还是个人资产。

### 生组关系

任何人都可以创办生组，只要在生制宪制框架下运行。

须经生门审核，符合要求与标准，获得背书后进入协作网络。

基本流程为：

**确认组织目标 → 发现机会 → 提案 → 尽调 → 立项 → 组队 → 配置资本与资源 → 建立产权与治理结构 → 经营 → 分配收益 → 扩大、退出或终止**

生组拥有经营自主性，同时接受约定范围内的监督。

实践机会通常由生组提供。生校学员参与实践，争议由生门处理。

### 生门协作体系

建立成员之间的：

- 资源发布
- 需求发布
- 生生匹配
- 项目匹配
- 商业合作
- 投资合作
- 就业合作
- 专业服务
- 信用评价

形成内部高信任、高效率的合作网络。

经背书的生组优先进入该网络。

### 生门风险体系

持续防范：

- 腐败
- 权力垄断
- 派系化
- 利益输送
- 财务风险
- 投资风险
- 法律风险
- 声誉风险
- 信息安全风险
- 成员道德风险
- 行灭道

发现问题，先止损、保核心，再纠错。不能用叠加新制代替切除病灶。

### 生门核心运转流程

生门的日常运行可归纳为六个主要循环。

#### 成员循环

**候选 → 考察 → 加入 → 参与 → 贡献 → 晋升 → 退出**

#### 治理循环

**提出议题 → 信息形成 → 讨论 → 决策 → 授权 → 执行 → 监督 → 纠错**

#### 资源循环

**资源进入 → 登记 → 明确权利主体 → 估值 → 配置 → 使用 → 回收 → 再配置**

#### 项目循环

**确认目标 → 发现机会 → 立项 → 组队 → 投资 → 建立生组或生财 → 经营 → 扩张或退出**

#### 财富循环

**生财创造价值 → 形成利润 → 按股权分配产出 → 按功劳调整产权 → 公共积累 → 再投资**

#### 协作循环

**成员需求 → 资源匹配 → 合作 → 结果评价 → 信用积累 → 更高层次合作**

因此，生门整体运行闭环为：

**吸纳生生 → 聚集资源 → 创办或背书生组 → 创造价值 → 分配成果 → 积累公共资产、能力与信用 → 输送标准、资本与人才，使更多组织按生道生长。**

### 其他

#### 创始阶段

体系运行平稳、共识形成之前，为创始阶段。

在此之前，生门创始人拥有最高权力，可以叫停生门内部一切事务，并指定各组织负责人。

运行平稳，共识形成后，创始人停止最高督导。此后生门内部按组织法，由生生选举产生负责人。

## 生校

### 生校定位

生校是教育性生组，为生门服务：

**发掘、培养、验证，向生门输送候选门人。**

生校可复制，须通过生门评审。

学员通过系统学习、训练和实践，不断接近生门成员标准。

学员即使最终不进入生门，也可以通过生校获得知识、能力、人脉、工作、项目、创业与合作机会。进入生校本身具有独立价值，但这不改变生校为生门服务的目的。

### 生校招生体系

建立：

- 社会传播
- 推荐
- 申请
- 初筛
- 面谈
- 测试
- 录取
- 入学建档

形成稳定的学员入口。

### 生校培养体系

先建立生道坐标系与判断—行动闭环，再展开细目。

培养内容包括：

#### 生道教育

理解核心思想与价值体系。

#### 认知能力

- 判断
- 学习
- 推理
- 决策
- 系统思考

#### 行动能力

- 执行
- 沟通
- 协作
- 管理
- 商业
- 创造价值

#### 意志品质

- 自律
- 责任
- 坚韧
- 延迟满足
- 抗压
- 自我纠偏

最终不是培养“知道很多的人”，而是培养：

**能够长期稳定创造价值的人。**

### 生校实践体系

教学必须与真实实践结合。

实践机会通常由生组提供。主要包括：

- 任务实践
- 团队项目
- 企业实习
- 社会实践
- 商业项目
- 创业
- 生门项目参与

通过现实结果验证学员，而不是只依赖考试。

学员自行承担培养成本。

### 生校评价体系

评价分为：

- **生道测验**：偏理论
- **股东横评**：偏实践

并持续观察：

- 知识
- 能力
- 行为
- 意志
- 信用
- 合作能力
- 责任承担
- 实际贡献

尤其需要观察学员在：

**压力、利益、失败、冲突和诱惑**

出现时的真实表现。

### 生校分流体系

根据个人发展结果，学员可以进入不同路径：

**继续学习 / 就业 / 项目合作 / 创业 / 与生门成员合作 / 成为候选门人**

其中：

**达到生门标准 → 候选期 → 深度考察 → 正式进入生门**

学员不因其在校身份而自动成为生生或股东。股东身份取决于生财是否接受其贡献；生生身份取决于生门的申请、学习与考核。

### 生校机会体系

生校同时建立机会网络：

- 就业机会
- 实习机会
- 创业机会
- 商业项目
- 投资机会
- 导师资源
- 专业资源
- 生门成员合作机会

让“学习—实践—机会”形成闭环。

### 生校教学迭代体系

持续记录：

- 学员表现
- 培养结果
- 社会结果
- 生门成员后续表现

再反向验证：

**什么样的人值得选择、什么方法真正有效、哪些课程没有作用。**

据此不断修改：

- 招生标准
- 教学内容
- 培养方法
- 考核制度
- 师资体系

教学标准的修订，须符合生门指定的要求，并由生门评价其结果。

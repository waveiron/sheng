你在把一份短视频文案做成竖屏成片。只呈现给定文案，不另写口号，不发明文案里没有的主张。

未写明的参数用默认值。文案必填。

```yaml
文案: # 必填。Markdown 路径。空行分段，句号分屏
语言: 自动 # 自动 | 中文 | 英文。自动时，句子以「.」结尾视为英文
声音: longlaobo_v3 # CosyVoice，模型 cosyvoice-v3-flash
语速: 1.3 # 1 为正常语速，小于 1 为慢速，大于 1 为快速
明暗: 暗 # 明 | 暗。明为白底黑字，暗为黑底白字
字号: 66 # Hiragino Sans GB W6
行宽上限: 960 # 像素
logo宽度: 106 # 裁掉透明边后的内容宽度
logo不透明度: 0.80 # 1 为完全不透明
logo垂直位置: 0.80 # 标志中心在画面高度上的比例，水平居中
淡入: 0.18 # 秒
淡出: 0.18 # 秒
句间停顿: 0.30 # 秒。句末是句号时，两句之间收到这么长
导出: 是 # 是：写到工程 render/。否：只做可预览工程
覆盖已有成片: 否 # 否：不动文案旁边已有的 mp4
```

其余固定值：1080×1920，30 帧。开头静音 0.18 秒，第一声前留 0.03 秒，最后一声后再留 0.55 秒。一句内部若不以句号结束，间隔用 0.14 秒。行距为字号的 0.32。

明暗决定底色、字色和标志：

- 暗：黑底，白字，`meta/logo/build/logo@3x.png`
- 明：白底，黑字，`meta/logo/build/logo@3x.png`

画面

- 同一时刻只显示一句。一句可以多行。
- 去掉句末句号，不显示「。」和「.」。
- 不显示逗号。中文「，」或英文「,」的位置换行，仍是同一句、同一屏。
- 字随旁白逐个出现。整行先按最终排版占位，未出现的字透明，位置不跳。已经出现的字随整句一起淡入、淡出。
- 淡入从该句第一个字出现时开始。淡出在该句时间结束时结束。句子短于淡入加淡出，或会与下一句重叠时，缩短到两句不同时可见。
- 成片从第 0 秒起淡入。最后一声结束后淡出，不超过结尾留白。整幅一起淡，含标志。标志在这场淡入里走到 logo 不透明度，淡出时从这里回到 0。句子之间标志不闪。
- 标志先按透明通道裁到内容，再缩到 logo 宽度，再乘 logo 不透明度。

排版

- 中文：逗号处断行。某一段仍超过行宽上限时，按字符换行，不拆成新的一句。
- 英文：逗号处断行。一行放不下时，只在词与词之间断开，不拆单词。能放下的切法里行数最少；行数相同则各行宽度尽量接近。换行吃掉的那个空格不显示。词与词之间的空格要留出，并占住最终位置。
- 英文行框要包住下伸字母（y、g、p、q），不要被下一行压住。
- 每一行各自居中。

旁白

- 整篇合成一次，不要逐句合成再拼接。
- 用逐字时间戳对齐。标点不占一个发音；逗号和空格的出现时间，取前一个字的结束时间。
- 中文句子直接相连。英文句子之间加一个空格再送去合成。
- 合成后从后往前收句间静音，再裁开头、留结尾，最后前面补上开头静音。时间戳跟着这些裁切移动。
- 密钥从本机 DashScope 配置读取。不要把密钥写进仓库、成片或这份提示词。

工程

- 用 HyperFrames。文案是内容来源。旁白 wav 和时间戳是时间来源。画面按这些时间排，时间轴可拖动。
- 改文案或声音，只重做旁白和时间戳。改字号、排版、明暗或标志，只重做画面。
- 工程放在文案同名文件夹里。成片写到该文件夹的 `render/`。文件名是工程名加序号，从 1 起，例如 `工程名-1.mp4`。这个序号已存在就用下一个空号。
- 先检查通过，再看关键帧：开头只有标志、逗号多行、英文打到一半时词不跳、下伸字母不撞行、换句时两句不重叠。然后按参数决定是否导出。
- 不提交，除非用户明确要求。
